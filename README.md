# chongwu · 优选宠物展示板

手机优先的宠物店展示页，带底部快捷联系与电话 / Telegram / WhatsApp 入口。

## 本地改联系方式
编辑 `index.html` 里的 `CONFIG`：
- `name` / `tagline` / `address` / `hours`
- `phone` / `telegram` / `whatsapp`

也可链接参数覆盖，例如：
`?name=我的店&phone=+85512...&telegram=https://t.me/xxx`

## 部署
推 `main` 后可开 GitHub Pages（Source: Deploy from branch → `/`）。
